# Install `@osva-ai/connector-freshdesk`

Source-only until npm bootstrap (see [RELEASE-CHECKLIST-freshdesk.md](./RELEASE-CHECKLIST-freshdesk.md)).

```bash
npm install @osva-ai/connector-freshdesk@0.1.0
```

Required env: `OSVA_CONNECTOR_FRESHDESK_DOMAIN`, `OSVA_CONNECTOR_FRESHDESK_API_KEY`. Mutations require `OSVA_CONNECTOR_FRESHDESK_NOTES_ENABLED` / `OSVA_CONNECTOR_FRESHDESK_STATUS_ENABLED`, `OSVA_CONNECTOR_FRESHDESK_HOST_WRITES_APPROVED`, and `OSVA_CONNECTOR_FRESHDESK_ALLOWED_RESOURCE_IDS`.
