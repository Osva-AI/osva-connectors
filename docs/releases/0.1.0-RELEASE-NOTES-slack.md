# Release notes (draft) — `@osva-ai/connector-slack@0.1.0`

**Status:** Draft for first public npm release. **Not published** as of Slack v0.1.0 preparation.

## Summary

First public npm release of the OSVA Slack connector: MCP stdio server with **five read tools** and **two write tools** (posting disabled unless `OSVA_CONNECTOR_SLACK_WRITE_ENABLED=true`).

## Included MCP tools

| Tool                    | Mutating | Description                  |
| ----------------------- | -------- | ---------------------------- |
| `slack.auth.test`       | No       | Token and workspace identity |
| `slack.channel.list`    | No       | Channel discovery            |
| `slack.channel.info`    | No       | Channel metadata             |
| `slack.message.history` | No       | Bounded message history      |
| `slack.message.thread`  | No       | Bounded thread replies       |
| `slack.message.post`    | Yes      | Plain-text channel message   |
| `slack.message.reply`   | Yes      | Plain-text thread reply      |

## Platform and dependencies

- **Node.js:** `>=24`
- **Transport:** MCP stdio (`osva-connector-slack` CLI)
- **Connector SDK:** `@osva-ai/connector-sdk@1.1.0-rc.2`
- **Slack API:** Web API over HTTPS (`https://slack.com/api/`), native `fetch` client

## Security and data handling (tested vs deployment)

**Tested in CI / acceptance**

- Fixed Slack methods only (no arbitrary API execution)
- Bearer token in header only; redaction in errors
- Channel allowlist optional env guard
- Write enable flag default **false**
- Bounded HTTP (2 MiB) and MCP JSON (256 KiB)
- Packaged tarball install + MCP smoke (seven tools, write-disabled, missing-token exit)
- Hermetic Vitest against loopback mock Slack HTTP

**Deployment assumptions (operator responsibility)**

- Slack app scopes, workspace policies, and bot channel membership
- Protection of `OSVA_CONNECTOR_SLACK_BOT_TOKEN`
- OSVA ToolPolicy / human approval before mutating tools
- Treat Slack message content as untrusted

## Reliability (tested)

- Finite operation deadline (`OSVA_CONNECTOR_SLACK_TIMEOUT_MS`)
- MCP cancellation propagates to HTTP and retry waits
- Read-only: at most **one** retry for eligible 429/5xx/network within deadline
- Writes: **no** automatic retry; ambiguous failures require verification in Slack

## Known limitations

- No OAuth installation flow, Events API, or multi-workspace token store in v0.1.0
- Public and private channels only (no DMs)
- Plain text posts only (no blocks, files, or impersonation)
- Connector SDK dependency is an **RC** pin for Profile V1 compatibility
