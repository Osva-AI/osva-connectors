# `@osva-ai/connector-gsc` 0.1.0 (draft)

First public release candidate for the Google Search Console read-only MCP connector.

## Highlights

- Eight MCP tools: property discovery, Search Analytics (custom + page/query presets), sitemaps, URL Inspection.
- Google ADC / service account authentication via `google-auth-library`.
- Bounded output (256 KiB), request deadlines, single retry for transient read errors.
- Hermetic tests with mock Google HTTP fixtures (no live API in CI).

## Requirements

- Node.js 24+
- Google Search Console API enabled
- Search Console property access for the credential
- OAuth: `webmasters.readonly` (most tools); `webmasters` for URL Inspection

## Not included

- No write/mutation tools
- No interactive OAuth onboarding in the connector binary
- Package **not published** until bootstrap `npm publish` per [RELEASE-CHECKLIST-GSC.md](../RELEASE-CHECKLIST-GSC.md)
