# Release notes — `@osva-ai/connector-npm@0.1.1`

**Status:** Draft for M19.3 SDK realignment patch.

## Summary

Patch release republishing `@osva-ai/connector-npm` with **`@osva-ai/connector-sdk@1.1.4`** on the npm tarball. Read-only npm registry tools and HTTP client behavior are unchanged from **`0.1.0`**.

## Why a new version

npm versions are **immutable**. Registry **`0.1.0`** pins connector-sdk **`1.1.3`**. Install **`0.1.1`** (or later) for SDK **`1.1.4`**.

## Platform and dependencies

- **Node.js:** `>=24`
- **Connector SDK:** `@osva-ai/connector-sdk@1.1.4` (exact pin)

## Install

See [INSTALL-NPM.md](../INSTALL-NPM.md).

```bash
npm install @osva-ai/connector-npm@0.1.1
```
