# `@osva-ai/connector-meta-ads` 0.1.0 (draft)

First public release of the OSVA Meta Ads MCP connector (read-only Marketing API v26.0).

## Highlights

- Ten MCP tools for ad account discovery, campaign structure, and bounded Insights reporting.
- Environment-based Meta access token configuration with optional `appsecret_proof`.
- Optional ad account allowlist, cursor pagination with host validation, HTTP reliability (deadline, single retry), and 256 KiB structured output budgets.

## Tools

- `meta.adAccount.list`, `meta.adAccount.get`
- `meta.campaign.list`, `meta.adSet.list`, `meta.ad.list`
- `meta.insights.account`, `meta.insights.campaign`, `meta.insights.adSet`, `meta.insights.ad`, `meta.insights.breakdown`

## Requirements

- Node.js 24+
- `@osva-ai/connector-sdk@1.1.0-rc.2`
- Meta access token with `ads_read`

## Install

See [docs/INSTALL-META-ADS.md](../INSTALL-META-ADS.md).

## Known limitations

- No OAuth onboarding or token storage in v0.1.0.
- No async Insights export jobs.
- No mutation tools.
