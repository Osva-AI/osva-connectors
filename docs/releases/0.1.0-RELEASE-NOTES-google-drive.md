# `@osva-ai/connector-google-drive` 0.1.0 (draft)

First public release candidate for the Google Drive read-only MCP connector.

## Highlights

- Eight MCP tools: file list/get/read/export, folder list, shared drives, change tracking.
- Google ADC / service account authentication via `google-auth-library` (`drive.readonly`).
- Bounded structured output (256 KiB), content byte budgets, deadlines, one retry for safe reads.
- Hermetic tests with mock Drive HTTP fixtures (no live API in CI).

## Requirements

- Node.js 24+
- Google Drive API enabled
- Drive access for the credential (sharing / shared drives)
- OAuth: `https://www.googleapis.com/auth/drive.readonly`

## Not included

- No write/mutation tools
- No interactive OAuth onboarding in the connector binary
- No MCP artifact delivery for binary exports (PDF/XLSX) in v0.1.0
- Package **not published** until bootstrap `npm publish` per [RELEASE-CHECKLIST-GOOGLE-DRIVE.md](../RELEASE-CHECKLIST-GOOGLE-DRIVE.md)
