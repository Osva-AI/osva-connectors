# Release notes (draft) — `@osva-ai/connector-github@0.3.0`

**Status:** Draft for first public npm release. **Not published** as of C3.3 implementation.

## Summary

First public npm release of the OSVA GitHub connector: MCP stdio server with five GitHub tools, production mutation safety, runtime output budgets, and packaged-install acceptance tests.

## Included MCP tools

| Tool                          | Description                                               |
| ----------------------------- | --------------------------------------------------------- |
| `github.repository.get`       | Repository metadata (read)                                |
| `github.issue.list`           | Issue list with pagination (read; pull requests excluded) |
| `github.issue.get`            | Single issue metadata (read)                              |
| `github.issue.create`         | Create issue (**mutating**)                               |
| `github.issue.comment.create` | Create issue comment (**mutating**)                       |

## Platform and dependencies

- **Node.js:** `>=24`
- **Transport:** MCP stdio (`osva-connector-github` bin)
- **Connector SDK:** `@osva-ai/connector-sdk@1.1.0-rc.2` (release candidate)

## Security and operations

- **GitHub token:** Fine-grained PAT via `OSVA_CONNECTOR_GITHUB_TOKEN`; least-privilege permissions per tool (see [INSTALL.md](../INSTALL.md)).
- **Authorization:** MCP discovery does not imply OSVA ToolPolicy approval or human sign-off.
- **Mutations:** Production stdio path uses `createGithubOctokit()` — **one POST** per create/comment invocation; no connector-level retries; ambiguous write failures use `retryable: false` and verify-on-GitHub messaging.
- **Untrusted content:** GitHub issue/comment text is data, not instructions; agent-level prompt-injection defenses remain in the calling runtime.

## Output budgets (C3.1)

- **Guaranteed:** `JSON.stringify(structuredContent)` ≤ **256 KiB** UTF-8 per tool call.
- **Not guaranteed:** Full MCP `CallToolResult` size (SDK duplicates JSON in `content[].text`).
- Optional metadata: `*Truncated`, `issuesTruncated` (distinct from GitHub `hasNextPage`).

## Known limitations

- No OAuth or managed credential vault in this package.
- No production GitHub API base URL override (targets `api.github.com`).
- Injected custom Octokit instances are outside production mutation no-retry guarantees.
- SDK dependency is an **RC** build; pin intentionally for Connector Profile V1 compatibility testing.
