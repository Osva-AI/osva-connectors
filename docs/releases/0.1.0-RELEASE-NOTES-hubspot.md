# `@osva-ai/connector-hubspot` 0.1.0

First public release of the OSVA HubSpot MCP connector (read-only CRM).

## Highlights

- Ten read-only MCP tools: contacts, companies, deals (list/get), structured CRM search, deal pipelines, owners, and associations.
- HubSpot API **2026-09** on `https://api.hubapi.com` with Bearer auth from environment only.
- Property allowlists, default PII minimization (`INCLUDE_PII=false`), bounded HTTP/output, and cursor pagination without following provider next URLs.
