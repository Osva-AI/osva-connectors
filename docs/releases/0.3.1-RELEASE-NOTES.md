# Release notes — `@osva-ai/connector-github@0.3.1`

**Status:** Draft for M19.3 SDK realignment patch.

## Summary

Patch release republishing `@osva-ai/connector-github` with **`@osva-ai/connector-sdk@1.1.4`** on the npm tarball. Tool names, input schemas, and runtime behavior are unchanged from **`0.3.0`**.

## Why a new version

npm versions are **immutable**. Registry **`0.3.0`** still pins connector-sdk **`1.1.0-rc.2`**. Install **`0.3.1`** (or later) for SDK **`1.1.4`**.

## Platform and dependencies

- **Node.js:** `>=24`
- **Connector SDK:** `@osva-ai/connector-sdk@1.1.4` (exact pin)

## Install

See [INSTALL.md](../INSTALL.md).

```bash
npm install @osva-ai/connector-github@0.3.1
```
