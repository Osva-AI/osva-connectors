# Release notes (draft) — `@osva-ai/connector-shopify@0.1.0`

**Status:** Draft for first public npm release. **Not published** as of S3 preparation.

## Summary

First public npm release of the OSVA Shopify connector: MCP stdio server with **seven read-only Admin GraphQL tools** for shop metadata, catalog, non-PII orders, scoped inventory levels, and locations.

## Included MCP tools (all read-only)

| Tool                            | Description                                   |
| ------------------------------- | --------------------------------------------- |
| `shopify.shop.get`              | Shop metadata                                 |
| `shopify.product.list`          | Products with search + cursor pagination      |
| `shopify.product.get`           | Single product summary                        |
| `shopify.order.list`            | Non-PII order list                            |
| `shopify.order.get`             | Non-PII order detail with bounded line items  |
| `shopify.inventory.levels.list` | Inventory levels scoped by location or item   |
| `shopify.location.list`         | Fulfillment locations (no physical addresses) |

**No mutation tools.**

## Platform and dependencies

- **Node.js:** `>=24`
- **Transport:** MCP stdio (`osva-connector-shopify` CLI)
- **Connector SDK:** `@osva-ai/connector-sdk@1.1.0-rc.2` (release candidate)
- **Shopify Admin API default version:** `2026-10` (override via `OSVA_CONNECTOR_SHOPIFY_API_VERSION`)

## Security and data handling (tested vs deployment)

**Tested in CI / acceptance**

- Fixed read-only GraphQL documents; no Admin mutations
- Host allowlist (`*.myshopify.com` / canonical store handle)
- Sanitized MCP errors (no `shpat_` tokens, raw provider stacks, or credential headers)
- Order outputs exclude customer PII fields at normalization
- Bounded HTTP (2 MiB) and structured MCP JSON (256 KiB) budgets
- Packaged tarball install + MCP smoke (seven tools, schemas, missing-config exit)

**Deployment assumptions (operator responsibility)**

- Shopify **scopes** and [protected customer data](https://shopify.dev/docs/apps/launch/protected-customer-data) compliance remain on your app
- MCP hosts must protect `OSVA_CONNECTOR_SHOPIFY_ACCESS_TOKEN` and treat catalog/order text as untrusted content
- OSVA ToolPolicy / human approval as your platform defines — MCP `tools/list` is not approval

## Reliability (tested)

- Finite operation deadline (`OSVA_CONNECTOR_SHOPIFY_TIMEOUT_MS`)
- MCP cancellation propagates to HTTP and retry backoff
- GraphQL `THROTTLED` / HTTP `429` / transient 5xx → at most **one** read-only retry (~1s) within the deadline
- Cursor pagination metadata preserved; connector-side `*Truncated` flags when output budget requires shortening lists

## Known limitations

- No OAuth install flow or multi-store routing
- No webhooks or incremental sync
- Order history may be limited by Shopify without **`read_all_orders`**
- Variant and line-item previews are bounded (not full nested pagination)
- Connector SDK dependency is an **RC** pin for Connector Profile V1 compatibility testing
- Retry backoff is fixed (~1s), not computed from `restoreRate`
