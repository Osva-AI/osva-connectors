# Release notes — `@osva-ai/connector-shopify@0.1.1`

**Status:** Draft for M19.3 SDK realignment patch.

## Summary

Patch release republishing `@osva-ai/connector-shopify` with **`@osva-ai/connector-sdk@1.1.4`** on the npm tarball. Seven read-only Shopify tools and GraphQL behavior are unchanged from **`0.1.0`**.

## Why a new version

npm versions are **immutable**. Registry **`0.1.0`** still pins connector-sdk **`1.1.0-rc.2`**. Install **`0.1.1`** (or later) for SDK **`1.1.4`**.

## Platform and dependencies

- **Node.js:** `>=24`
- **Connector SDK:** `@osva-ai/connector-sdk@1.1.4` (exact pin)

## Install

See [INSTALL-SHOPIFY.md](../INSTALL-SHOPIFY.md).

```bash
npm install @osva-ai/connector-shopify@0.1.1
```
