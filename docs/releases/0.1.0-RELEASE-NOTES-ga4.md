# Release notes (draft) — `@osva-ai/connector-ga4@0.1.0`

**Status:** Draft for first public npm release. **Not published** as of G3 preparation.

## Summary

First public npm release of the OSVA Google Analytics 4 connector: MCP stdio server with **seven read-only tools** for property discovery, reporting metadata, custom core reports, realtime reports, and acquisition/ecommerce presets.

## Included MCP tools (all read-only)

| Tool                     | Description                                      |
| ------------------------ | ------------------------------------------------ |
| `ga4.property.list`      | Discover accessible GA4 properties (Admin API)   |
| `ga4.property.get`       | Property metadata                                |
| `ga4.metadata.get`       | Dimensions and metrics catalog with local search |
| `ga4.report.run`         | Bounded custom core report                       |
| `ga4.report.realtime`    | Realtime report                                  |
| `ga4.report.acquisition` | Session acquisition preset                       |
| `ga4.report.ecommerce`   | Ecommerce overview or product breakdown          |

**No mutation tools.**

## Platform and dependencies

- **Node.js:** `>=24`
- **Transport:** MCP stdio (`osva-connector-ga4` CLI)
- **Connector SDK:** `@osva-ai/connector-sdk@1.1.0-rc.2` (release candidate)
- **Google auth:** `google-auth-library` with ADC / service account (`analytics.readonly` scope)
- **APIs:** Analytics Admin API v1beta, Analytics Data API v1beta

## Security and data handling (tested vs deployment)

**Tested in CI / acceptance**

- Read-only REST; fixed tool shapes (no arbitrary Google method execution)
- Sanitized MCP errors (no access tokens, refresh tokens, or private keys)
- Bounded HTTP (2 MiB) and structured MCP JSON (256 KiB) budgets
- Packaged tarball install + MCP smoke (seven tools, schemas, missing-config exit)
- Hermetic Vitest coverage against loopback mock Google HTTP

**Deployment assumptions (operator responsibility)**

- Google Cloud API enablement and GA4 **property access** assignment
- Protection of `GOOGLE_APPLICATION_CREDENTIALS` and service account JSON
- MCP hosts must treat dimension/metric/cell values as untrusted content
- OSVA ToolPolicy / human approval as your platform defines — MCP `tools/list` is not approval

## Reliability (tested)

- Finite operation deadline (`OSVA_CONNECTOR_GA4_TIMEOUT_MS`) covering auth, HTTP, body read, and retry backoff
- MCP cancellation propagates to HTTP and retry waits
- HTTP 429 / `RESOURCE_EXHAUSTED` / transient 5xx → at most **one** read-only retry within the deadline
- Report pagination exposes `rowCount`, `rowsReturned`, and `hasMoreRows` when derivable from Google; `rowCountIsLowerBound` when Google omits `rowCount`

## Known limitations

- No interactive OAuth onboarding in the connector binary
- Realtime tools limited to realtime-compatible fields
- Ecommerce/acquisition presets use fixed query shapes
- Connector SDK dependency is an **RC** pin for Connector Profile V1 compatibility testing
- `propertyQuota` uses Google `QuotaStatus` objects when present; not requested on every report call
