# `@osva-ai/connector-whatsapp` 0.1.0

First public release of the WhatsApp Business Cloud API MCP connector (Graph **v26.0**).

## Tools

- `whatsapp.businessAccount.get`
- `whatsapp.phoneNumber.list`
- `whatsapp.phoneNumber.get`
- `whatsapp.businessProfile.get`
- `whatsapp.template.list`
- `whatsapp.template.get`
- `whatsapp.analytics.get` (template analytics, DAILY / CLOUD_API)
- `whatsapp.template.send` (disabled by default; host opt-in allowlist required)

## Security and policy

- Fixed `https://graph.facebook.com` host; no Graph passthrough.
- Template send: single recipient, approved templates only, no OTP/authentication category, no automatic retries on ambiguous outcomes.
- Recipient opt-in enforced via `OSVA_CONNECTOR_WHATSAPP_ALLOWED_RECIPIENTS` (host configuration).

## Limitations

- No webhook listener, conversation history, or delivery-status persistence in this package.
- Template send supports body text parameters only (no header media or button passthrough).
