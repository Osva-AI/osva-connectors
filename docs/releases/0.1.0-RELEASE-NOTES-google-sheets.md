# `@osva-ai/connector-google-sheets` 0.1.0 (draft)

First public release of the OSVA Google Sheets MCP connector.

## Highlights

- Eight MCP tools: spreadsheet metadata, sheet listing, bounded value reads, and optional RAW writes when `OSVA_CONNECTOR_GOOGLE_SHEETS_WRITE_ENABLED=true`.
- Google ADC / service account auth via `google-auth-library`; read-only vs full spreadsheets scope based on write enablement.
- Optional spreadsheet ID allowlist via `OSVA_CONNECTOR_GOOGLE_SHEETS_ALLOWED_SPREADSHEETS`.
- Hermetic tests with mock Sheets HTTP server; package acceptance tarball + MCP smoke (GS1).
