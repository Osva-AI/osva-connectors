# `@osva-ai/connector-stripe` 0.1.0

First public release of the OSVA Stripe MCP connector (read-only payments and billing).

## Highlights

- Ten read-only MCP tools: account, balance, balance transactions, PaymentIntents, charges, refunds, subscriptions, invoices, and minimal customer metadata.
- Fixed origin `https://api.stripe.com` with pinned **`Stripe-Version: 2025-09-30.clover`**.
- Restricted-key friendly Bearer auth from environment only; optional customer allowlist and live-mode guard.
- Integer minor-unit amounts preserved; bounded pagination (`startingAfter`) without following provider URLs; 256 KiB MCP output budget.
