# `@osva-ai/connector-google-ads` 0.1.0

First public release of the OSVA Google Ads MCP connector (read-only).

## Highlights

- Nine MCP tools for customer discovery, campaign/ad group/keyword/search term/asset reporting, and constrained GAQL queries.
- Google Ads REST API **v26** (`googleads.googleapis.com`) with bounded Search pagination.
- OAuth via `google-auth-library` (`adwords` scope); optional legacy `developer-token` header.
- Customer ID validation and optional allowlist (`OSVA_CONNECTOR_GOOGLE_ADS_ALLOWED_CUSTOMERS`).
- GAQL allowlisting (SELECT-only, bounded dates, field/resource gates).
- Hermetic Vitest suite with mock HTTP provider; packaged MCP acceptance scripts.

## Install

See [docs/INSTALL-GOOGLE-ADS.md](../INSTALL-GOOGLE-ADS.md).

## Known limitations

- No write/mutate tools; read-only behavior is enforced at the connector surface.
- Search term and some keyword rows may be omitted by Google privacy rules.
- Cross-account currency totals are not aggregated.
- `ads.report.query` accepts structured allowlisted fields only (not arbitrary GAQL strings).
