# Install `@osva-ai/connector-bigcommerce`

Source-only until npm bootstrap (see [RELEASE-CHECKLIST-BIGCOMMERCE.md](./RELEASE-CHECKLIST-BIGCOMMERCE.md)).

```bash
npm install @osva-ai/connector-bigcommerce@0.1.0
```

Required env: `OSVA_CONNECTOR_BIGCOMMERCE_STORE_HASH`, `OSVA_CONNECTOR_BIGCOMMERCE_ACCESS_TOKEN`. Mutations require `OSVA_CONNECTOR_BIGCOMMERCE_WRITE_ENABLED` and `OSVA_CONNECTOR_BIGCOMMERCE_HOST_WRITES_APPROVED`.
